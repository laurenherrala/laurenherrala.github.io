# Lauren Herrala

A plain HTML, CSS, and JavaScript portfolio. No build step or dependencies.

## Pages

- `index.html`: Home slideshow, ordered 1–4.
- `work.html`: Work images in a single column, ordered 1–8.
- `about.html`: About placeholder.
- `contact.html`: Email and Instagram links.

The web images are in `assets/home/` and `assets/work/`. Desktop originals are unchanged. Playfair Display is bundled in `assets/fonts/` with its license.

## Preview

From this folder, run `python3 -m http.server 8000`, then open http://localhost:8000.

## GitHub Pages

In the repository, open **Settings → Pages**. Select **Deploy from a branch**, choose **main** and **/(root)**, then click **Save**.

GitHub Pages URL: https://laurenherrala.github.io/website/
